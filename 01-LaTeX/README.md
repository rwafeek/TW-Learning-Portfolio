# LaTeX Documentation

## 1. Introduction

LaTeX is a document preparation system used to create professional documents. It is widely used for academic reports, research papers, books and technical documents.

## 2. Objectives

- Understand the basics of LaTeX.
- Learn the structure of a LaTeX document.
- Understand LaTeX commands and environments.
- Create mathematical equations.
- Compile a LaTeX document into PDF format.

## 3. Basic Structure of LaTeX

A simple LaTeX document contains three main parts:

1. Document class declaration.
2. Document body.
3. Document ending.

Example:

```latex
\documentclass{article}

\begin{document}

Hello World!

\end{document}
```

## 4. Important LaTeX Commands

| Command | Purpose |
|---|---|
| `\documentclass{article}` | Defines the document type |
| `\begin{document}` | Starts the document |
| `\end{document}` | Ends the document |
| `\title{}` | Defines the title |
| `\author{}` | Defines the author |
| `\section{}` | Creates a section |
| `\textbf{}` | Makes text bold |
| `\textit{}` | Makes text italic |

## 5. Mathematical Expressions

LaTeX supports mathematical expressions and equations.

Example:

```latex
E = mc^2
```

A displayed equation can be written using:

```latex
\[
E = mc^2
\]
```

## 6. Advantages of LaTeX

- Professional document formatting.
- Excellent mathematical typesetting.
- Automatic numbering of sections and equations.
- Suitable for academic and technical writing.
- Supports tables, images and references.

## 7. Applications

- Research papers.
- College assignments.
- Technical reports.
- Books and presentations.
- Scientific publications.

## 8. Conclusion

LaTeX is a powerful document preparation system. It helps users create well-structured and professionally formatted academic and technical documents.
